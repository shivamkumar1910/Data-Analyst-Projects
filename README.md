## Suggested Project Structure

Each project can follow this layout:

```text
Project-Name/
├── README.md
├── data/
│   ├── raw/
│   └── cleaned/
├── python/
├── sql/
├── powerbi/
├── reports/
├── requirements.txt
└── notebooks/   # optional, if used
```

This structure helps keep analysis, reporting, and business insights separated and easy to explain.
